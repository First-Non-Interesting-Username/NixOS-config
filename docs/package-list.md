# Package List

## packages.btop

Btop wrapped with nix-wrapper-modules.

- Gruvbox Dark theme
- Vim keys by default

## packages.fastfetch

Fastfetch wrapped with nix-wrapper-modules.

- Displays hardware and software specs using organized sections and spacing.
- Replaces text labels with Nerd Font icons and a blue color scheme.
- Simplifies Memory and Disk readouts to show used vs. total capacity.

## packages.foot

Foot wrapped with nix-wrapper-modules.

- Gruvbox Dark theme
- JetBrainsMono Nerd font
- Disabled bell and CSDs

## packages.sops-easy

Automatically detects and configures the SSH host Ed25519 key for sops age encryption.
