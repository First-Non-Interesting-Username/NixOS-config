# Hosts

## Laptop

This is my main personal laptop.
New changes are often tested here first, because I usually don't store sensative data on it.

Specs:

- Ryzen 3 Pro 7330U
- Vega 7
- 32GB of RAM 3200MT/s DDR4
- 512GB NVMe SSD

At this moment, this machine runs Plasma based desktop config.

This host can be used as a template for other configs.

## Server

This is the main services VM on my Proxmox server.
I run my services with [Nix-Podman-Stacks](https://github.com/Tarow/nix-podman-stacks).

Specs:

- i5 8500T 4c
- UHD 630
- 24GB of RAM 2666MT/s DDR4
- 100GB NVMe SSD
- 512GB SATA SSD
- 14TB HDD in a SATA to USB enclosure

This host SHOULD NOT be used as a template for other configs.

- Creator or author of the work the character comes from MUST NOT be a bad person, as defined by my subjective moral standards.
