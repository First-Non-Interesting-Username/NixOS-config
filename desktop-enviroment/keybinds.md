# Keybinds

This file documents my keybindings.
I want to have them the same across all desktop environments.
If any of the DE modules are inconsistent with this, please open an issue and I'll fix it as soon as I can.

If unspecified, all shortcuts are with super key.

| Action                     | Shortcut                      |
| -------------------------- | ----------------------------- |
| Open Workspace Overview    | Just Super                    |
| Terminal                   | Return                        |
| App Launcher               | Space                         |
| File Manager               | E                             |
| Clipboard Manager          | B                             |
| Screenshot (area)          | (no Super) Shift + Print      |
| Session Menu               | Escape                        |
| Close Window               | Q                             |
| Fullscreen                 | F                             |
| Maximize                   | G                             |
| Show Desktop               | D                             |
| Focus Direction            | h/j/k/l or Arrow Keys         |
| Swap Window                | Ctrl + h/j/k/l or Arrow Keys  |
| Resize                     | Shift + h/j/k/l or Arrow Keys |
| Switch Workspaces          | 1-0                           |
| Move to Workspace          | Shift + 1-0                   |
| Move to Workspace Silently | Ctrl + 1-0                    |
| Toggle Special Workspace   | S                             |
| Move to Special Workspace  | Shift + S                     |
| Move to Special Silently   | Ctrl + S                      |

Besides that, I also have standard audio/brightness keybinds.
